# Space Survivor — Codex Instructions

## Project
Space Survivor is a 2D arcade game developed in Python using pygame-ce.

## Environment
- OS: Ubuntu on WSL2
- Python: 3.14
- Game library: pygame-ce
- Virtual environment: .venv
- Version control: Git and GitHub

## Coding Rules
1. Follow PEP 8.
2. Use English names for variables, functions, and classes.
3. Use type hints where practical.
4. Keep code modular and readable.
5. Do not introduce unnecessary dependencies.
6. Add comments for non-obvious logic.
7. Use pygame-ce through `import pygame`.

## Workflow
1. Inspect existing code before modifying it.
2. Explain the proposed changes before implementing major features.
3. Implement features in small, testable steps.
4. Run available checks after changes.
5. Summarize modified files and explain how the code works.
6. Ask for approval before installing dependencies.
7. Do not commit, push, delete files, or modify Git configuration without explicit permission.

## Safety
- Never modify files outside the project directory.
- Never access or expose credentials or secrets.
- Never use destructive Git commands without explicit approval.
- Do not modify the virtual environment directly.
